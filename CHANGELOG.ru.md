# История изменений

[English version](CHANGELOG.md)

Всё, что сделано после тега `v0.1.0b1` (25 сентября 2026), по
`git log v0.1.0b1..HEAD`: 754 коммита, из них 289 `feat` и 173 `fix`, остальное —
документация, тесты, CI и стиль. Kvist в стадии beta, более нового тега пока нет.

## Не выпущено

### Добавлено

- **Цикл агента.** Пачки действий с несколькими shell-командами одновременно,
  фоновые shell-команды (`job_output`, `job_stop`), ожидание и расписание, которые
  будят агента по времени, режим плана по предложению модели, десять помощников,
  best-of и совет в отдельных worktree, живой счётчик контекста и `/context`.
- **Память и заметки.** Итоги сессий и фоновое чтение, чтобы Kvist помнила прошлые
  сессии; `KVIST.md` как её собственный блокнот проекта; хранилище скиллов на
  SQLite.
- **Провайдеры.** Вход по подписке ChatGPT Plus/Pro, ожидание, пока кончится
  окно лимита подписки, нативные вызовы инструментов через адаптер Anthropic,
  Kimi Code, Inception, дополнительные HTTP-заголовки для своих провайдеров
  (`/headers`), встроенная таблица цен по моделям и множитель цены AnyModel рядом с
  каждой моделью.
- **Песочница и подтверждения.** Контейнерный режим для задач бенчмарков,
  авторежим, который запоминает разрешения и заранее одобряет скиллы, и net broker
  для доступа скиллов к сети.
- **Скиллы.** Платформа скиллов во всех фронтендах, встроенные скиллы browser,
  design, visualize, desktop, documents, Gmail, Telegram и `kvist_docs`,
  `app_screen` для графических программ на собственном скрытом экране агента и
  команда `/website`.
- **Интерфейсы.** Терминал OpenCode (`--frontend opencode`), Glass (терминальный
  интерфейс на Rust поверх фотографии), голосовой фронтенд, Kvist Desktop,
  планшетная раскладка страницы для телефона, Android-приложение, экран
  первоначальной настройки и экран установщика для `curl | bash`, веб-клиент,
  интеграция с Zed, inline-дополнение и генерация сообщений коммитов в плагинах
  IDE.
- **Удалённая работа и платформы.** Ядро на сервере, которое переживает свои
  фронтенды, по ssh (`plink` из PuTTY на Windows), экспериментальный запуск на
  FreeBSD, OpenBSD и NetBSD, сборка для Termux.
- **Отзывы.** `/feedback` составляет черновик issue на GitHub, показывает его как
  письмо и отправляет только после вашего согласия.
- **Kvist Cloud.** Облачный сервис с тарифами, пробным периодом, входом по ChatGPT
  на сервере, выдачей машины на каждого и админ-панелью (AGPL, в `cloud/`).

### Исправлено

- **Провайдеры.** Отказы по reasoning-effort и `tool_choice` от своих шлюзов и
  DeepSeek больше не ломают запуск; после смены провайдера модель выбирается
  заново; если поток теряет аргументы вызова, запрос повторяется без потока.
- **Песочница.** Лимиты памяти для дочерних процессов, системные бинарники root
  считаются доверенными при запуске от root, команды `sandbox=host` получают ваш
  настоящий `HOME`, `plink` не подключается к хосту, который вы не подтвердили,
  shell работает из домашнего каталога.
- **Windows.** Дочерние процессы больше не наследуют stdin ядра (зависание в
  best-of), пути в импортированных сессиях Cursor и Continue, удаление скиллов.
- **Сессии.** Набранное уточнение остаётся в журнале незавершённой задачи.
- **Интерфейсы.** Диалог плана показывает предложенный план, полосы прокрутки для
  тёмных тем IDE, уведомление об обновлении — это toast, а не ответ, и много
  мелких исправлений экрана и ввода в терминале, Glass, вебе и IDE.
- **Установщики и CI.** Установка расширения VS Code повторяется без `--force`,
  зависимости и таймауты сборки Termux, платформо-зависимые тесты.
