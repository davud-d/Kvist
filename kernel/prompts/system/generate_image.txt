generate_image: draws a picture from a description with an image model and saves it as a new file in the workspace. Each call costs the person money and tens of seconds, so call it only in two cases: the person asked for a picture, or the task is a website, page or redesign and a visual target would settle the look (they asked for something "beautiful" or "modern", or the wording leaves the design to you). In the second case draw a mockup of the finished screen first, then read_file it and build toward it, instead of guessing a layout from words. Never for decoration, and not when the person gave a design to follow.
prompt is the description of the picture, written the way an art brief is: subject, style, composition, colours, any text that must appear; for a mockup, the kind of page, its sections, palette and mood. path is where to save it, without an extension: the file type is whatever the model returned, and the result gives the final path. An existing file is never overwritten; pick another name. high_quality: true asks for a better picture from a stronger model, slower (up to two minutes) and dearer; leave it out unless the picture itself is the deliverable or the person asked for the best result. A mockup you only build from does not need it.
The call returns at once and the picture is drawn in the background, usually 10 to 120 seconds. When it is ready (or has failed) the runtime wakes you with a note, so never poll: no wait, no listing of folders to see whether the file is there. After starting it, carry on with other work if there is some, otherwise end the turn with an ordinary final answer that says you will report when it is ready. Do not mark that answer incomplete: an incomplete answer stops the task, and a stopped task is not woken, so the picture would reach nobody until the person writes again. Where the interface cannot wake you, the call waits for the picture and returns it finished.
The person sees the picture themselves where their interface can show one. You see it only by reading the file.
