# Kvist Local Web

`kvist-web` — локальная панель управления рабочими папками, долговечными сессиями, несколькими агентами и
агентами по SSH. Это фронтенд поверх существующего ядра Kvist, а не вторая реализация агента.

*(Полное описание на английском: [README.md](README.md). Контракт API: [API.md](API.md).)*

## Телефон в локальной сети

```bash
kvist-web --lan                 # слушает 0.0.0.0:9671, печатает код сопряжения
kvist-web --lan --new-code      # заменяет код (все сопряжённые телефоны сопрягаются заново)
```

`--lan` нужен приложению для Android (`frontends/android`) и браузеру телефона по адресу
`http://<компьютер>:9671/m/`: это отдельный пиксельный интерфейс (`client/mobile/`) поверх того же API.
Режим включается только явно и сам не стартует:

- Код (12 символов, сохраняется с приватными правами в `~/.kvist/web/lan-code`) и есть токен доступа:
  он уходит паролем Basic в каждом запросе.
- Маяк поиска отвечает на UDP-пробу на порту 9672 именем и портом компьютера, и только приватным адресам.
  Если порт занят, поиск выключается, а сопряжение по адресу работает.
- Проверка Host принимает IP-адреса частных диапазонов (имена нет), поэтому страница с DNS-rebinding до
  сервера не достанет. Без `--lan` проверка осталась прежней.
- Трафик идёт по обычному HTTP внутри сети. Кто там знает код, тот управляет агентом на этом компьютере;
  не используй режим в сети, которой не доверяешь.
