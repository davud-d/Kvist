# Kvist Local Web

`kvist-web` — локальная панель управления рабочими папками, долговечными сессиями, несколькими агентами и
агентами по SSH. Это фронтенд поверх существующего ядра Kvist, а не вторая реализация агента.

*(Полное описание на английском: [README.md](README.md). Контракт API: [API.md](API.md).)*

## Телефон в локальной сети

```bash
kvist-web --lan                 # обслуживает телефоны на 0.0.0.0:9671 (следующий свободный порт, если занят)
kvist-web --forget-phones       # все телефоны должны спросить заново
```

Обычно запускать это самому не нужно: **ядро, запуская агента, поднимает веб** (`kernel/phone_link.py`),
держит к нему одно соединение, а контроллер завершается через минуту после ухода последнего агента
(`--auto-exit`). Выключить: `KVIST_PHONE=0` или `"phone_access": false` в `~/.kvist/config.json`. Если порт
уже занят контроллером без `--lan` (например, службой автозапуска), телефоны не увидят компьютер, пока его не
перезапустят с `--lan`.

У приложения для телефона (`frontends/android` или браузер телефона по `http://<компьютер>:9671/m/`)
собственный пиксельный интерфейс (`client/mobile/`) поверх того же API, поэтому доверенный телефон умеет то же,
что браузер: запускать и переключать сессии, останавливать агента, отвечать на запросы, вводить `/`-команды,
менять модель, рассуждение и роль.

- **Доверие.** В первый раз телефон нажимает на компьютер в списке, и **компьютер спрашивает владельца в
  окне рабочего стола** (zenity, yad или kdialog на Linux, диалог на macOS, окно сообщения на Windows; без
  рабочего стола спросить нельзя, и телефону об этом скажут). После «Разрешить» телефон получает личный токен,
  он хранится хешем в `~/.kvist/web/devices.json`, и дальше каждый запрос несёт его паролем Basic. Вопрос один
  за раз, а после отказа 30 секунд тишины: никто в сети не завалит владельца окнами.
- **Поиск.** Маяк отвечает на UDP-пробу на порту 9672, только с приватных адресов: id компьютера, имя хоста,
  операционная система (`linux`, `macos`, `windows` и читаемое название), имя пользователя и порт. Это и видит
  телефон. Прочитать может любой в той же сети: такова цена списка с именами. Если порт занят, поиск выключен,
  а ввод адреса работает.
- **Проверка Host.** Только IP-адреса частных диапазонов, не имена: страница с DNS-rebinding до контроллера не
  достанет. Без `--lan` проверка прежняя.
- **Ограничения.** Обычный HTTP внутри локальной сети: не оставляй режим включённым в сети, которой не
  доверяешь. Доверенный телефон управляет агентом на этом компьютере, включая команды.
