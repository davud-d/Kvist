# веб-клиент kvist: спека редизайна

## рамки
- меняем только frontends/web-local/kvist_web/client/ и tests/browser/. ядро, ssh/, bridge/, runtime/, electron, image-attachments.js не трогаем.
- единственные правки вне client/ и tests/browser/: исключение для сервера и строки package-data для новых файлов клиента в pyproject.toml (fonts/*.woff2, fonts/OFL.txt, features/feed.js и далее).
- исключение для сервера: .woff2 в белом списке /assets/* (http_api.py:256) и одна строка mimetypes.add_type("font/woff2", ".woff2") (http_api.py:24), потому что python до 3.14 знает .woff2 только через системный mime.types, которого может не быть. csp не расширяется.
- единственная правка ядра: журнал сессии берёт тот же stream_id, что живой поток (kernel/session_events.py, kernel/event_stream_ui.py, коммит 823ddda), иначе ответ из стрима и из истории не склеиваются по stream_id. поля событий и версия протокола не менялись.
- без фреймворков и сборки: чистые es-модули, csp script-src 'self' остаётся. внешних шрифтов и cdn нет, инструмент работает офлайн.
- только тёмная тема. цвета заводим токенами, чтобы светлую тему потом добавить заменой набора.
- /assets/* отдаёт только .js .css .svg .png и .woff2 (font/woff2). webp и другие форматы не использовать.
- фикс дельт стрима уже в main (a1b1dbf). его не переделываем, reducer должен с ним совпадать.

## принципы
1. плоский фон. без градиентов, теней, свечения, blur, стекла. удалить --glass-*, --bg-subtle, cursor glow.
2. один акцент. он стоит только на: активная сессия, фокус поля ввода, кнопка отправки, непрочитанное, активная вкладка.
3. рамка есть только там, где она что-то разделяет.
4. плотность: строка сайдбара 28px, ui 13px, текст ответа 14px/1.55, mono 12.5px.
5. анимация только если она несёт состояние. prefers-reduced-motion выключает все анимации.
6. антишаблон. text-transform: uppercase запрещён. цепочек "a · b · c" в нижней строке и шапке нет, элементы разделяет отступ. подписи над блоками только там, где без них блок непонятен. mono только для кода, путей, вывода инструментов и статусной строки; остальной текст (заголовки, подписи, селектор модели) идёт шрифтом --sans.
7. оранжевый цвет только у белки. других тёплых акцентов в интерфейсе нет: --warn жёлтый, --err красный, --accent голубой.

## токены
один блок :root. все цвета в oklch. остальной css не содержит цветовых литералов, кроме transparent и currentColor. значения стартовые, финал подбираем на макете.
- фон: --bg-0 oklch(19.9% 0.011 260.7) страница, --bg-1 oklch(23.3% 0.011 254.1) панели, --bg-2 oklch(27.5% 0.015 256.8) приподнятое и hover. стартовые значения получены переводом прежних hsl скриптом на node.
- линии: --line oklch(31.5% 0.017 255.6) разделители без требований к контрасту, --line-strong oklch(56% 0.022 253.5) граница поля ввода и полоса user-блока. светлота --line-strong поднята с 39% до 56%, иначе контраст 1.55:1 на --bg-2.
- текст: --text oklch(92.1% 0.006 255.5), --text-2 oklch(74.2% 0.016 257.2), --text-3 oklch(65.7% 0.017 257.2).
- акцент: --accent oklch(76% 0.12 224). оттенок 224 взят скриптом с голубой (светлой) полосы шарфа белки, светлота 0.70-0.80 в кадрах frontends/tui/ink/mascot/frames/; тёмно-синее тело шарфа даёт 260. chroma 0.12 стартовая. оттенки через color-mix(in srgb, var(--accent) 14%, transparent)
- статусы: --ok oklch(74% 0.14 150), --warn oklch(74% 0.14 95), --err oklch(74% 0.14 22). светлота и chroma общие, различаются оттенком. --warn жёлтый, не оранжевый. статус не передаётся одним цветом: рядом всегда форма (кольцо, точка, галочка, крестик) или текст.
- радиус: --r 4px, поле ввода 6px
- шрифты: --sans системный стек. --mono JetBrains Mono (self-hosted, client/fonts/JetBrainsMono.woff2, лицензия client/fonts/OFL.txt), запасной ui-monospace. внешних адресов нет, @font-face с font-display: swap. файл с кириллицей и латиницей, переменная толщина 400-600; если он не влезает в лимит 120 КБ, два файла (Regular, Medium), подрезанные pyftsubset до латиницы, кириллицы, пунктуации и псевдографики. источник: официальный релиз github.com/JetBrains/JetBrainsMono, лицензия сверяется с файлом из релиза.
- рамки: исключение для сервера описано в разделе «рамки». csp не расширяется.

### контраст
расчёт по WCAG, проверка против --bg-0, --bg-1 и --bg-2 (все три фона).
- текст (--text, --text-2, --text-3, а также --accent, --ok, --warn, --err там, где они красят текст) не ниже 4.5:1.
- не текст не ниже 3:1: граница поля ввода, кольца фокуса и спиннера, точки индикаторов, --line-strong.
- граница поля ввода это --line-strong. отдельный токен заводится, только если --line-strong не проходит; цветовых токенов не больше 14.

## раскладка
- сайдбар 248px, шапка 40px, колонка ленты max 760px по центру.
- шапка: заголовок сессии, под ним путь воркспейса mono 12px --text-3. справа вкладки Files, Diff, Terminal. у активной подчёркивание 2px --accent, у остальных --text-2.
- поле ввода внизу колонки: рамка --line, радиус 6px, без тени. в фокусе рамка --accent. слева значок вложения, справа селектор модели (--sans, --text-2) и кнопка отправки (квадрат 28px, заливка --accent, заблокирована при пустом тексте).
- подсказка "Ctrl ↵ to send" остаётся под полем, --text-3.

## сайдбар
- выпадающий список воркспейсов сверху убрать. воркспейсы остаются группами в списке сессий: имя группы 11px --text-3, сворачивается.
- New session: строка без рамки и заливки, значок + слева, хоткей справа.
- строка сессии 28px, заголовок обрезается по ширине, справа область индикатора 14px.
- индикатор по session.execution и session.unread, приоритет сверху вниз: waiting_for_user точка --warn, failed точка --err, running и starting крутящееся кольцо 12px --accent, unread точка --accent, остальное (idle, finished, stopped) пусто.
- если unread при running, заголовок строки weight 600.
- серые точки с opacity .4 удалить.

## лента: блоки
один тип блока, один рендер. рамок и аватаров нет, подписи "You" и "Kvist" убрать.
- user: полоса 2px --line-strong слева, без заливки и рамки. вложенные картинки миниатюрами под текстом.
- text: события message, final, plan, stream_*. markdown без рамки. plan получает подпись "plan" 11px --text-3.
- reasoning: события reasoning_*. одна строка "thinking Ns" --sans --text-3, свёрнута, раскрывается по клику. пока идёт стрим, секунды тикают. сейчас клиент эти события игнорирует.
- tool: события step, action_result, action_output, связь по call_id. строка 24px: статус (кольцо, галочка или крестик), действие, путь или первая строка команды с обрезкой, справа exit_code или время. клик раскрывает output в mono, max-height 320px с прокруткой. вызовы с общим batch_id собираются в группу "N calls".
- input: событие input_request, четыре вида: choice, text, secret, confirm. рамка --accent. secret это поле password. после ответа блок сворачивается в строку с результатом.
- notice: error, sandbox_notice, journal_notice, session_ended, connection.*. строка 12px mono, error цветом --err.
- вне ленты: usage, status, session_title, route, hello. они идут в шапку и нижнюю строку.
- таблица имён инструментов одна, в blocks.js. дубли из session.js (62-70) и views.js (4) убрать.

## reducer
- client/features/blocks.js, чистая функция reduce(state, envelope) без dom, без глобального состояния, без часов и случайности. envelope: {seq?, ts?, durable?, event}.
- через неё идут и живой sse, и восстановление из /api/v1/history.
- в reducer живут: склейка stream_chunk и reasoning_chunk (append=true добавляет дельту, append=false или отсутствие поля заменяет текст, stream_commit ставит финальный), связь по call_id, группы по batch_id, секунды reasoning, дедупликация по seq.
- тесты: node --test, frontends/web-local/tests/client/blocks.test.mjs, без браузера. кейсы: дельты стрима, снимок при append=false, дельты reasoning, commit. сценарий стрима в redesign.mjs остаётся.
- client/features/feed.js рисует блоки по ключу блока и обновляет только изменённые.

## нижняя строка
- статический текст "Connecting…" и "Idle" из index.html убрать.
- соединение показывать только когда оно не в порядке: connecting дольше 1.5 с, reconnecting, offline. когда всё в порядке, ничего не показывать.
- состояние агента текстом не показывать, его показывают индикаторы сайдбара и белка. неизвестное значение execution не превращать молча в idle (store.js:20, session.js:382): console.warn один раз.
- слева context % mono.

## поле ввода
- первый "+" (вложения) оставить как значок скрепки. image-attachments.js живёт в frontends/gui/electron/renderer и отдаётся веб-сервером как запасной. не править его, стилизовать только css веб-клиента.
- второй "+" (#composer-tools) убрать. палитра команд остаётся на Ctrl+K и в меню шапки.
- селектор "Local" (#server-switcher) спрятать за одной константой SHOW_SERVERS = false. код модалки серверов не удалять, удалённый режим заморожен.

## diff
- client/features/diff.js, чистая функция parseDiff(text) возвращает файлы: путь, add, del, хунки, строки с видом (add, del, ctx) и номерами old и new.
- вид: заголовок файла со счётчиком +n -m и сворачиванием, заголовок хунка приглушён, два столбца номеров --text-3, фон строк через color-mix от --ok и --err (14%).
- строки +++ и --- не красить как add и del.
- если report не похож на diff (повреждённый журнал, текстовое сообщение), показать как notice. пустой: "no changes yet".
- пейджинг 1000 строк оставить, на файл.
- тесты node --test на parseDiff: frontends/web-local/tests/client/diff.test.mjs.

## белка
- шаг выполняется только по прямой команде, после просмотра кадров. до этого не начинать.
- источник: 6 png в frontends/tui/ink/mascot/frames/ (frame_1.png ... frame_6.png), 2 fps в tui. кадры 1254x1254 нарисованы крупными пикселями, часть кадров без альфа-канала (фон непрозрачный).
- подготовка: скриптом найти натуральную сетку пикселей арта (шаг пикселя), уменьшить кадры nearest-neighbor до этой сетки, проверить альфа-канал каждого кадра. спрайт это один png, 6 кадров в одну полосу.
- показ: целый множитель натурального размера, image-rendering: pixelated. дробного масштаба нет.
- место: белка стоит в пустой сессии и в строке у поля ввода. в строке сайдбара её нет.

## приёмка
- в styles.css нет цветовых литералов вне :root. нет box-shadow, backdrop-filter, linear-gradient, radial-gradient, filter: blur. проверка grep.
- цветовых токенов не больше 14. все цвета в oklch.
- контраст по разделу «контраст» проходит, проверка скриптом на node по всем парам токен-фон.
- rg -n 'text-transform' styles.css даёт пусто.
- rg -n '·' client/index.html client/features/*.js даёт пусто, кроме строк markdown-парсера, если они там есть.
- в styles.css нет внешних адресов (http://, https://, //).
- шрифт отдаётся с кодом 200 и типом font/woff2.
- цветовых литералов вне :root нет: rg -nP '#[0-9a-fA-F]{3,8}\b|\brgba?\(|\bhsla?\(|(?<![\w-])(white|black)(?![\w-])' styles.css, все совпадения только внутри :root.
- node --test зелёный. сценарии playwright зелёные, устаревшие удалены с пояснением в коммите.
- размер client/ это сумма байт файлов .js, .css, .html в kvist_web/client/ без fonts/, измеряется командой stat -c %s. предел 180 КиБ (184 320 байт). fonts/ не больше 120 КБ суммарно.
- о пределе: прежнее число 140 КиБ взято из аудита без обоснования. для localhost размер клиента на скорость не влияет. ограничители это отсутствие фреймворков и зависимостей (раздел «рамки»), а предел только ловит случайный рост.
- нет горизонтального скролла на 1280x720 и на ширине 390px.
