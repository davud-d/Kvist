# веб-клиент kvist: спека редизайна

## рамки
- меняем только frontends/web-local/kvist_web/client/ и tests/browser/. ядро, ssh/, bridge/, runtime/, electron не трогаем.
- без фреймворков и сборки: чистые es-модули, csp script-src 'self' остаётся. внешних шрифтов и cdn нет, инструмент работает офлайн.
- только тёмная тема. цвета заводим токенами, чтобы светлую тему потом добавить заменой набора.
- /assets/* отдаёт только .js .css .svg .png. webp и другие форматы не использовать.
- фикс дельт стрима уже в main (a1b1dbf). его не переделываем, reducer должен с ним совпадать.

## принципы
1. плоский фон. без градиентов, теней, свечения, blur, стекла. удалить --glass-*, --bg-subtle, cursor glow.
2. один акцент. он стоит только на: активная сессия, фокус поля ввода, кнопка отправки, непрочитанное, активная вкладка.
3. рамка есть только там, где она что-то разделяет.
4. плотность: строка сайдбара 28px, ui 13px, текст ответа 14px/1.55, mono 12.5px.
5. анимация только если она несёт состояние. prefers-reduced-motion выключает все анимации.

## токены
один блок :root. остальной css не содержит цветовых литералов, кроме transparent и currentColor. значения стартовые, финал подбираем на макете.
- фон: --bg-0 hsl(215 18% 9%) страница, --bg-1 hsl(215 16% 12%) панели, --bg-2 hsl(215 15% 16%) приподнятое и hover
- линии: --line hsl(215 14% 20%), --line-strong hsl(215 14% 28%)
- текст: --text hsl(215 15% 90%), --text-2 hsl(215 10% 68%), --text-3 hsl(215 8% 56%). контраст --text-3 на --bg-1 не ниже 4.5:1, проверить расчётом.
- акцент: --accent hsl(195 80% 60%). оттенки через color-mix(in srgb, var(--accent) 14%, transparent)
- статусы: --ok hsl(145 50% 55%), --warn hsl(38 85% 60%), --err hsl(355 80% 66%)
- радиус: --r 4px, поле ввода 6px
- шрифты: inter и другие web-шрифты не использовать. --sans системный стек, --mono ui-monospace с запасными.

## раскладка
- сайдбар 248px, шапка 40px, колонка ленты max 760px по центру.
- шапка: заголовок сессии, под ним путь воркспейса mono 12px --text-3. справа вкладки Files, Diff, Terminal. у активной подчёркивание 2px --accent, у остальных --text-2.
- поле ввода внизу колонки: рамка --line, радиус 6px, без тени. в фокусе рамка --accent. слева значок вложения, справа селектор модели (mono, --text-2) и кнопка отправки (квадрат 28px, заливка --accent, заблокирована при пустом тексте).
- подсказка "Ctrl ↵ to send" остаётся под полем, --text-3.

## сайдбар
- выпадающий список воркспейсов сверху убрать. воркспейсы остаются группами в списке сессий: имя группы 11px --text-3, сворачивается.
- New session: строка без рамки и заливки, значок + слева, хоткей справа.
- строка сессии 28px, заголовок обрезается по ширине, справа область индикатора 14px.
- индикатор по session.execution и session.unread, приоритет сверху вниз: waiting_for_user точка --warn, failed точка --err, running и starting крутящееся кольцо 12px --accent, unread точка --accent, остальное (idle, finished, stopped) пусто.
- если unread при running, заголовок строки weight 600.
- серые точки с opacity .4 удалить.

## лента: блоки
один тип блока, один рендер. рамок и аватаров нет, подписи "You" и "Kvist" убрать.
- user: полоса 2px --line-strong слева, без заливки и рамки. вложенные картинки миниатюрами под текстом.
- text: события message, final, plan, stream_*. markdown без рамки. plan получает подпись "plan" 11px --text-3.
- reasoning: события reasoning_*. одна строка "thinking Ns" mono --text-3, свёрнута, раскрывается по клику. пока идёт стрим, секунды тикают. сейчас клиент эти события игнорирует.
- tool: события step, action_result, action_output, связь по call_id. строка 24px: статус (кольцо, галочка или крестик), действие, путь или первая строка команды с обрезкой, справа exit_code или время. клик раскрывает output в mono, max-height 320px с прокруткой. вызовы с общим batch_id собираются в группу "N calls".
- input: событие input_request, четыре вида: choice, text, secret, confirm. рамка --accent. secret это поле password. после ответа блок сворачивается в строку с результатом.
- notice: error, sandbox_notice, journal_notice, session_ended, connection.*. строка 12px mono, error цветом --err.
- вне ленты: usage, status, session_title, route, hello. они идут в шапку и нижнюю строку.
- таблица имён инструментов одна, в blocks.js. дубли из session.js (62-70) и views.js (4) убрать.

## reducer
- client/features/blocks.js, чистая функция reduce(state, envelope) без dom, без глобального состояния, без часов и случайности. envelope: {seq?, ts?, durable?, event}.
- через неё идут и живой sse, и восстановление из /api/v1/history.
- в reducer живут: склейка stream_chunk и reasoning_chunk (append=true добавляет дельту, append=false или отсутствие поля заменяет текст, stream_commit ставит финальный), связь по call_id, группы по batch_id, секунды reasoning, дедупликация по seq.
- тесты: node --test, frontends/web-local/tests/client/blocks.test.mjs, без браузера. кейсы: дельты стрима, снимок при append=false, дельты reasoning, commit. сценарий стрима в redesign.mjs остаётся.
- client/features/feed.js рисует блоки по ключу блока и обновляет только изменённые.

## нижняя строка
- статический текст "Connecting…" и "Idle" из index.html убрать.
- соединение показывать только когда оно не в порядке: connecting дольше 1.5 с, reconnecting, offline. когда всё в порядке, ничего не показывать.
- состояние агента текстом не показывать, его показывают индикаторы сайдбара и белка. неизвестное значение execution не превращать молча в idle (store.js:20, session.js:382): console.warn один раз.
- слева context % mono.

## поле ввода
- первый "+" (вложения) оставить как значок скрепки. image-attachments.js живёт в frontends/gui/electron/renderer и отдаётся веб-сервером как запасной. не править его, стилизовать только css веб-клиента.
- второй "+" (#composer-tools) убрать. палитра команд остаётся на Ctrl+K и в меню шапки.
- селектор "Local" (#server-switcher) спрятать за одной константой SHOW_SERVERS = false. код модалки серверов не удалять, удалённый режим заморожен.

## diff
- client/features/diff.js, чистая функция parseDiff(text) возвращает файлы: путь, add, del, хунки, строки с видом (add, del, ctx) и номерами old и new.
- вид: заголовок файла со счётчиком +n -m и сворачиванием, заголовок хунка приглушён, два столбца номеров --text-3, фон строк через color-mix от --ok и --err (14%).
- строки +++ и --- не красить как add и del.
- если report не похож на diff (повреждённый журнал, текстовое сообщение), показать как notice. пустой: "no changes yet".
- пейджинг 1000 строк оставить, на файл.
- тесты node --test на parseDiff: frontends/web-local/tests/client/diff.test.mjs.

## белка
- шаг выполняется только по прямой команде, после просмотра кадров. до этого не начинать.
- источник: 6 png в frontends/tui/ink/mascot/frames/ (frame_1.png ... frame_6.png), 2 fps в tui. для веба нужен один png-спрайт на 6 кадров, показ 64px.

## порядок работ
после каждого шага: тесты, дифф, остановка до ответа.
0. база: сверка спеки с кодом, ветка web-redesign, классификация красных сценариев.
1. токены и css: новый :root, удаление эффектов, раскладка, js не менять.
2. blocks.js и тесты. только reducer, без dom; session.js, views.js, app.js и styles.css не меняются.
3. feed.js: переключение отрисовки на reducer, блоки user, text, tool, reasoning, notice, input.
4. сайдбар и индикаторы.
5. поле ввода и нижняя строка.
6. diff.js.
7. белка.
8. markdown: таблицы (парсер в ui.js их не знает).

## приёмка

- цветовых токенов не больше 14.
- node --test зелёный. сценарии playwright зелёные, устаревшие удалены с пояснением в коммите.
- размер client/ не больше 140 КБ.
- нет горизонтального скролла на 1280x720 и на ширине 390px.
