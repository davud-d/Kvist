# Kvist для Android

Окошко в агента, который работает на твоём компьютере. **На телефоне ничего не запускается**: приложение
находит в той же сети (за тем же роутером) компьютер с установленным Kvist, сопрягается с ним по короткому
коду и показывает его сессии: разговор, что агент запускает, и запросы, которые ждут тебя (разрешить или
отклонить команду, выбрать вариант). Пиксельный стиль, белка; с 1 декабря до конца февраля она в шарфе, и
идёт снег.

*(English: [README.md](README.md))*

## Как это устроено

```text
приложение (WebView, Kotlin)
  1. UDP-проба на широковещательный адрес подсети, порт 9672  ->  `kvist-web --lan` отвечает {name, port}
  2. GET http://<компьютер>:9671/ с кодом                     ->  200 = сопряжено, 401 = код неверный
  3. открывает http://<компьютер>:9671/m/                     ->  пиксельный интерфейс, его отдаёт компьютер
```

- Сам интерфейс отдаёт компьютер (`frontends/web-local/kvist_web/client/mobile/`), поэтому он всегда той же
  версии, что и Kvist на компьютере. В приложении только экран подключения
  (`app/src/main/assets/connect.html`); стили, спрайты и шрифты у него общие со страницей: сборка копирует
  их из веб-клиента, а не дублирует.
- Приложение говорит по тому же HTTP/SSE-контракту, что и браузерный интерфейс
  (`frontends/web-local/API.md`).
- Приложение не открывает никаких адресов, кроме сопряжённого компьютера. Страница компьютера не достаёт до
  канала сообщений приложения (он привязан к собственному origin приложения).

## Как пользоваться

На компьютере (Kvist установлен):

```bash
kvist-web --lan          # печатает код сопряжения; --lan --new-code заменяет его
```

В приложении компьютер появится сам; нажми на него и введи код. Если список пуст (некоторые роутеры
изолируют клиентов Wi-Fi, или файрвол режет UDP 9672), нажми **Ввести адрес** (`192.168.1.20` или
`192.168.1.20:9671`). Файрвол компьютера должен пускать телефон на TCP 9671.

**Безопасность.** Кто сидит в этой сети и знает код, тот управляет агентом на компьютере, включая команды,
которые тот просит запустить. Трафик внутри сети идёт по обычному HTTP; не включай `--lan` в сети, которой
не доверяешь. Код секретный: приложение хранит его в приватном хранилище и исключает из бэкапов.
`--new-code` отрезает все сопряжённые телефоны.

## Сборка

Нужны JDK 17+ (лучше 21) и Android SDK (платформа 36, build tools).

```bash
cd frontends/android
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME=$HOME/Android/Sdk ./gradlew :app:testDebugUnitTest :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В эмуляторе компьютер виден как `10.0.2.2`. `?winter=1` на экране подключения или на `/m/` показывает зимний вид
в любой месяц; `?winter=0` выключает его в сезон.
