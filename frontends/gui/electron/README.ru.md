# Kvist Desktop

*(English version: [README.md](README.md))*

Десктопное приложение: рабочее место с тредами поверх NDJSON-протокола Kvist версии 1.
Слева проекты и треды, в середине разговор, по требованию панель Review и выдвижная панель
команд. Оно не импортирует Python и не читает `.kvist/`: запускает ядро дочерним процессом и
говорит только по stdio-протоколу и через headless-вызовы `--session-op`, `--config-op`,
`--skill-op`, `--memory-op` и `--journal-op` ([`docs/UI_API.ru.md`](../../../docs/UI_API.ru.md)).

Оно стоит рядом с [`../electron-legacy`](../electron-legacy/README.md): мост main-процесса
(`src/kvist-process.js`, `protocol-state.js` и др.) взят оттуда, рендерер написан заново.

## Запуск

```bash
cd frontends/gui/electron
npm ci
npm start -- --workspace /путь/к/проекту
```

Если после `npm ci` у Electron нет бинарника (новый npm блокирует install-скрипты), один раз
выполни `node node_modules/electron/install.js`.

В исходниках приложение запускает `../../../.venv/bin/python -m kernel`; чтобы взять собранное
ядро, задай `KVIST_BINARY=/абсолютный/путь/к/kvist`. `KVIST_CONFIG_DIR=<папка>` позволяет
попробовать первый запуск на пустой конфигурации. Провайдера нужно подключить один раз:
*Настройки → Модели и провайдеры* принимает ключ API для каждого провайдера, выполняет вход
через ChatGPT и добавляет свой OpenAI- или Anthropic-совместимый адрес.

## Что внутри и что стоит на месте того, чего у Квиста нет

| Понятие | В Kvist Desktop |
|---|---|
| Треды в проектах | **Сессии** Kvist в **рабочих папках**. Тред восстанавливается из журнала событий сессии (`--session-op history`), поэтому открытый заново тред выглядит как живой. |
| Выбор модели и рассуждений | Чип под полем ввода: **провайдер + быстрая/умная модели** для следующей задачи и **роль** агента (авто, кодер, читатель, devops, чат). |
| Разрешения: обычные / полный доступ | **Спрашивать про опасное** или **Запрещать опасное**. Режима «разрешить всё» нет намеренно. В запросе может быть «Всегда разрешать» для его шаблона. |
| Подтверждения | Панель над полем ввода: команда, дифф перезаписи, разрешения навыков и сети; фокус на «Отклонить». Закрытое окно отказывает. |
| Локально / worktree / облако | Только **локально**. Ядро на сервере (`docs/remote.ru.md`) в это приложение не подключено. |
| Панель Review, дифф, коммит | **Правки агента** (из патча каждой записи в треде) и **Рабочее дерево** (git, `.kvist/` исключена). *Откатить* возвращает правки агента из журнала изменений. *Коммит* пишет сообщение через `--commit-message` и коммитит только отмеченные файлы. |
| Встроенный терминал | Панель **Команды** (`Ctrl+J`): все команды, которые агент запускал, в том числе фоновые, с живым выводом. Это не интерактивная оболочка. |
| Плагины, коннекторы, MCP | **Навыки**, **MCP-серверы** и **подключения к сервисам** (здесь только списки; управление через `--skill-op`, `--mcp-op`, `--connection-op`). |
| Memories | **Память**: что Kvist помнит о тебе и проекте, с кнопкой «Забыть». |
| Браузер / управление компьютером | Карточка **экрана** агента (живое превью, «Открыть в браузере») от навыков `browser` и `app_screen`. |
| Вход через ChatGPT | Вход и выход провайдера `chatgpt`. |
| Слэш-команды, `@` файлы | `/new /resume /review /commit /commands /skills /memory /folder /settings`; `@` дополняет файл проекта; картинки прикрепляются вставкой, перетаскиванием или `+`. |
| Поиск, горячие клавиши | `Ctrl+K` ищет треды и команды; `Ctrl+N`, `Ctrl+B`, `Ctrl+J`, `Ctrl+Shift+D`, `Ctrl+,`; `Esc` ставит агента на паузу. |

Не сделано: несколько задач одновременно (одна задача на приложение, другие треды открываются
после её конца), автоматизации, очередь сообщений во время работы
(`Enter` никогда не останавливает задачу, для этого есть «Пауза» и «Стоп»), комментарии к
строкам диффа.

Интерфейс на английском и русском (*Настройки → Общие*), светлая и тёмная темы.

## Устройство

```
src/        main-процесс: окно, IPC, операции ядра (core-ops.js), git.js, workspace-files.js
renderer/   index.html, styles.css, js/
  thread.js   события (живые или из журнала) -> элементы треда; чистая логика, без DOM
  timeline.js рисует их         composer.js  поле ввода          diff.js  unified-диффы
  panels.js   Review, команды, диалог коммита                   pages.js навыки, память, настройки
  sidebar.js  проекты и треды   app.js       связка
test/       node --test
```

## Тесты и сборка

```bash
npm test
npm run dist     # собирает ядро PyInstaller'ом в resources/bin, затем пакует
```

В `package.json` стоит `"workspaces": []`, чтобы electron-builder считал эту папку своим
корнем. `resources/bin/` и `.build/` — результат сборки.
