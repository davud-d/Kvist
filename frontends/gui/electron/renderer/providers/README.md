# Provider logos

Monochrome logos, copied here so the app works offline. The file names are the brand slugs the core reports in
`--config-info` (`kernel/config/brand_icons.py`). A brand without a file is drawn as a monogram.

- Most come from [Simple Icons](https://simpleicons.org) (CC0-1.0, see `LICENSE-simple-icons.md`).
- OpenAI, Groq, Cohere, Together, Fireworks, Cerebras, DeepInfra, Novita, Baseten, SambaNova, Nebius, Friendli,
  AI21, Zhipu, Z.ai, StepFun, Baichuan, Tencent, 01.AI and iFlytek come from
  [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons) (MIT, see `LICENSE-lobehub-icons.md`).

The logos are trademarks of their owners and appear only to say which provider or model a row is about.
