# Kvist Pixel (Tauri)

Настольный интерфейс Kvist в стиле пиксельной игры. Это фронтенд над тем же ядром, что и все остальные
(`docs/UI_API.md`), на Rust (Tauri 2) и обычном JavaScript.

*(English version: [README.md](README.md))*

## Что умеет

- **Дерево проектов слева.** Папка раскрывается в свои сессии; выбранная открывается (агент запускается, когда вы начинаете писать), точка показывает, какие работают.
- **Агенты рядом.** Каждый агент это отдельный процесс ядра в своей сессии. Слева список агентов,
  «отдаление» (`Ctrl+\`) показывает всех живыми плитками и приближает к выбранному.
- **Видно, что делают помощницы, и браузер агента** в правой панели (помощницы, экран, фоновые команды,
  контекст и изменённые файлы). Панель открывается сама, когда появляется помощница или экран.
- **Закрытый разговор**: вместо поля ввода баннер, Enter начинает новую сессию.
- **Картинки**: вставка, перетаскивание или `+`; они видны миниатюрами над сообщением. **Формулы** рисует KaTeX.
- **Настройки** (шестерёнка слева снизу) делают то же, что слэш-команды (роль, усилие, стиль, модели,
  сессии, изменения, откат...), и меняют вид: пять тем, размер, анимации вкл/выкл, прозрачность окна.
- Предложения плана, подтверждения команд и diff перезаписи показываются диалогами, как в других интерфейсах.

## Прозрачность окна

Прозрачно ли окно, решается при его создании. На macOS и Windows оно по умолчанию прозрачное. **На Linux оно по умолчанию непрозрачное**:
на некоторых графических стеках WebKitGTK ничего не рисует в прозрачном окне (замерено: прозрачное окно при выключенном DMABUF пустое,
а NVIDIA требует его выключить), поэтому прозрачность там включается вручную. Включите её в настройках («Прозрачное окно», приложение
перезапустится) или запустите с `--transparent`; `--opaque` снова выключает. Если окно вдруг пустое, запустите с `--safe`
(`KVIST_SAFE_RENDER=1`: непрозрачное окно и программный рендер); в меню приложений для этого есть действие «Safe mode». Выбор
сохраняется в `~/.kvist/desktop.json` (или `$KVIST_CONFIG_DIR`). Для Wayland и X11 больше ничего не нужно; прозрачному окну нужен
композитор, а размытие позади окна делает композитор, а не приложение.

## Запуск из репозитория

```bash
cd frontends/gui/tauri/src-tauri
cargo run                      # нужен .venv репозитория (ядро) или KVIST_CORE_CMD
cargo build --release --locked # target/release/kvist-tauri
```

На Linux нужны `libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `librsvg2-dev`. Тесты: `node --test "tests/*.test.mjs"` и
`cargo test`. Чтобы посмотреть страницу без Tauri, отдайте `ui/` любым статическим сервером: ответит
заглушка ядра (попробуйте слова `approve`, `plan`, `insult` в сообщении).

## Установка

Установщики релиза (`curl ... | bash`, `install.ps1`) предлагают **Kvist Pixel desktop app** с галочкой по умолчанию:
скачивают бинарник и добавляют в меню приложений (запись в лаунчере Linux, `~/Applications/Kvist Pixel.app`,
меню «Пуск» и ярлык на рабочем столе). Из репозитория `python scripts/installer/install.py` (или `install_app.py`) *собирает* его через cargo
после установки Rust и добавляет в то же меню; ничего не скачивает.

## Устройство

`src-tauri/` оболочка (`core.rs` процессы ядра, `ops.rs` операции с сессиями, `main.rs` команды) ·
`ui/js/` редьюсер, хранилище, действия, анимации, виды, панели · `ui/css/` тема и раскладка · `tests/` логика страницы.
Шрифты и KaTeX вложены, см. `THIRD_PARTY.md`.
