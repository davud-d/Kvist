# Kvist Pixel в облаке

*(English version: [README.md](README.md))*

Пиксельное окно [Kvist Pixel (Tauri)](../../frontends/gui/tauri/README.ru.md), скопированное сюда и изменённое
только там, где в облаке другие данные. Это просто файлы без сборщика: `cloud/frontend/build.mjs` копирует их в
`dist/pixel/`, а сервер отдаёт по адресу **`/pixel/`** (старые страницы остаются как были; в шапке есть ссылка
«Рабочее место»). У каждой сессии свой адрес, `/pixel/s/<id>` (непрозрачный id), так что ссылка открывает её; открыть её может только владелец.

## Что осталось тем же

Редьюсер, лента, диалоги, темы, белка, анимация и markdown/KaTeX — родные, от десктопного приложения. Они
работают без правок, потому что облако отдаёт события Kvist как есть (`cloud/docs/ARCHITECTURE.ru.md`, «Задача»).

## Что теперь облачные данные

| Десктопное приложение | Здесь |
| --- | --- |
| Папки проектов в левой панели | **Проекты**: «Добавить проект» создаёт папку на твоём сервере — клон одного из твоих репозиториев на GitHub или просто имя (имена не повторяются) |
| Сессия в папке | **Задача** (сессия) в проекте; панель показывает их, новые сверху |
| Кнопки окна, края для изменения размера | Убраны (это веб-страница); вместо них переключатель языка |
| Модели, роль, усилие, стиль ядра | **Ключ модели** человека (провайдер + ключ, проверяется при сохранении) |
| Настройки: сессии, откат, экспорт… | **Аккаунт**: ключ, тариф и оплата, выход; и внешний вид страницы |
| Инспектор: помощницы, экран, задачи, контекст | **Часы**, **Сервер**, **Экран**, файлы/контекст, помощницы, фоновые команды |
| — | В верхней полосе: **сколько осталось часов** и **состояние сервера** (спит, готов, работает…) |

* **Часы**: сколько осталось от тарифа, сколько потратила эта задача, журнал. «Докупить» открывает страницу тарифа.
* **Сервер**: машина (спит / готова / работает, vCPU, RAM, диск); можно разбудить, усыпить и скачать архив её файлов.
* Задача — это **сессия**: ей можно писать дальше. Первое сообщение запускает агента на твоём сервере, следующие
  идут в тот же разговор, и агент его помнит (если он остановился, облако запускает Kvist заново и возвращается в
  разговор; сообщение, отправленное пока агент работает, встаёт в очередь за его ходом). Разговор хранится, так
  что после перезагрузки он весь на месте. Пауза и стоп — в шапке задачи, у приостановленной есть кнопка
  «продолжить», вопросы агента — обычные диалоги.
* Вложений нет: облачная задача принимает только слова.

## Экран агента приватный

Вкладка **Экран** показывает браузер и рабочий стол агента. То, что агент там делает, так же приватно, как его
файлы: адрес и токен машины с неё не уходят, картинки тянутся, только пока вкладка открыта, лежат только в
памяти, а сервер отдаёт их вошедшему владельцу задачи и никому больше (другой аккаунт, администратор и
невошедший получают «не найдено»). Подробности и тесты: `cloud/docs/ARCHITECTURE.ru.md`,
«Экран агента (приватный)».

## Устройство папки

`js/cloud.js` аккаунт (часы, сервер, ключ, задачи) и чистые помощники страницы · `js/bridge.js` единственное место,
которое говорит с облаком (HTTP и WebSocket задачи) · `js/panels/` вкладки инспектора · `css/cloud.css` то, что
добавило облако · `tests/` чистая логика (`node --test "tests/*.test.mjs"`).

Шрифты и KaTeX — от десктопного приложения: см. [THIRD_PARTY.md](THIRD_PARTY.md).
